# Ghibli Portfolio

A fully responsive, Ghibli-inspired portfolio site for Akshay Kumar Patil.

## Run locally

1. Activate the virtual environment.

```powershell
.\\.venv\\Scripts\\Activate.ps1
```

2. Start the Python backend.

```powershell
python server.py
```

3. Open `http://127.0.0.1:8000`.

## Notes

- The site uses plain HTML, CSS, and JavaScript on the frontend.
- The Python backend serves the page and the resume-driven data as JSON.
